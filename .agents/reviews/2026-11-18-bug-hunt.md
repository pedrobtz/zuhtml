# zuhtml bug hunt, 2026-11-18

Commit `b181a95`. Hunters: 3 on Fable 5.2 (`claude-fable-5-2`), run one at
a time with no access to each other's reports or to the assurance audit's
findings (#81 to #86). Slices: (1) the R layer, (2) decoding: input routes,
encodings, prescan, tree, parse limits, (3) extraction and emitters:
selectors, text, tables, URLs, metadata, forms, serialization, Markdown.
Coordinator on Opus 5.5 (`claude-opus-5-5`): the target map, re-running
every trigger against a fresh install of the pinned commit, grading, issues.

Built here: macOS x86_64, R 4.6.2, Apple clang 17, R's libiconv 1.11.
Unverified: glibc and Windows `iconv()` (every decoder finding is for macOS
libiconv and may differ elsewhere); network URLs in `html_read()`; the C core
under ASan was not rebuilt by a hunter (the existing sanitizer and fuzz gates
cover memory safety).

Probe scripts are in `2026-11-18-bug-hunt-probes/`; run with `HL` set to a
library holding zuhtml at `b181a95`. `rerun/` holds the coordinator's
re-runs.

## Findings

Severity: high (memory safety, or wrong bytes on the wire or on disk; here a
local-file read), medium (wrong result or broken documented contract), low
(misleading or cosmetic). All are reproduced by the coordinator unless
marked.

### 1. Parse JSON-LD without letting jsonlite open files or URLs — #88, high, reproduced

- Where: `R/metadata.R:112`.
- Trigger: a JSON-LD block whose text is an existing file path, then
  `html_json_ld(parse = TRUE)`; the file's content is returned. A
  `http(s)://` text is fetched (inspection of `jsonlite::fromJSON()`).
- Cause: `jsonlite::fromJSON()` treats short non-JSON text as a path or URL.
- Fix: `jsonlite::parse_json()`, or wrap the text so it is only JSON.
- Family: 4 in effect (a string has a second meaning); found by hunters 1
  and 3 independently.
- Test the suite lacked: a block naming an existing temp file and a
  loopback URL; assert `NULL`, nothing read.

### 2. Flush iconv's held character for windows-1258 and windows-1255 — #89, medium

- Where: `R/parse.R:508`. `iconv("Hello", "CP1258", "UTF-8")` is `"Hell"`.
- Trigger: any page in either encoding ending in one of 78 (1258) or 23
  (1255) byte values loses its last character, silently.
- Family: 1. Siblings: every stateful iconv converter; only these two lost
  data here.
- Test the suite lacked: each byte as the final byte, against the WHATWG
  index.

### 3. Keep valid control characters instead of replacing them — #90, medium

- Where: `src/vendor/gumbo/utf8.c:158`, `:198`.
- Trigger: `html_parse("<p>x\u0080y")` gives U+FFFD and a `utf8-invalid`
  problem; `&#x81;` keeps U+0081.
- Fix: a vendored patch, offered upstream.
- Family: 4. Siblings: every ISO-8859-x and `encoding = "iso-8859-1"` decode
  of 0x80 to 0x9F goes through this.

### 4. Resolve `encoding =` through the label table — #91, medium

- `encoding = "iso-8859-1"` decodes 0x93 to U+FFFD, `<meta charset=iso-8859-1>`
  to U+201C. HTTP labels `x-sjis`, `windows-31j`, `iso-8859-8-i`,
  `x-mac-roman` are refused. Family 3: the table guards one route of two.

### 5. Mark unmarked UTF-8 instead of `enc2utf8()` in a C locale — #92, medium

- `R/parse.R:344`, siblings `R/select.R:110`, `R/attributes.R:54`,
  `R/select.R:142`. Under `LC_ALL=C` an unmarked UTF-8 string parses `café`
  as `caf` plus bogus `<c3>` tags; selectors and `html_attr(default =)`
  likewise; the selector error position counts bytes. Family 3.

### 6. Treat a non-ASCII charset label as unknown — #93, medium

- `R/sniff.R:119`: `simpleError` "input string 1 is invalid". Hunters 1 and
  2 independently. Family 4.

### 7. Look up form owners and itemrefs without building a selector — #96, medium

- `R/forms.R:102`: a `form` attribute with a newline or over 16 KiB makes
  `html_forms()` fail for the whole document. Sibling `itemref` at
  `R/metadata.R:195` (inspection). Family 3.

### 8. Leave absent microdata URL properties empty — #97, medium

- `R/metadata.R:249` resolves `""` to the base URL. Hunters 1 and 3. Family 4.

### 9. Ignore SVG and MathML `<base>`, forms, JSON-LD and script text — #98, medium

- `R/links.R:97`, `R/forms.R:65`, `R/metadata.R:106`, `kind_of()` in
  `src/zuh_text.c`. Family 3: `html_title()`, `html_tables()` and
  `html_list()` filter on namespace, these do not.

### 10. Pass `html_read()`'s arguments by name on the URL route — #99, medium

- `R/parse.R:232`: positional and partial arguments that work for a path
  fail or shift for a URL. Family 3.

### 11. Keep a table column character when conversion would change a value — #100, medium

- `R/table.R:357`: `"0,123"` → 123, 20-digit integers lose precision,
  `"1e999"` → `Inf`, a nbsp `thousands` never matches. Family 1.

### 12. Markdown emitter (`src/zuh_markdown.c`) — #101 to #107, medium and low

- #101 (medium): `!` before a link makes an image; a `:-:` line after a
  pipe line makes a GFM table. `put_escaped()`.
- #102 (medium): adjacent code spans fuse; edge spaces dropped. `put_code()`.
- #103 (medium): nested and adjacent emphasis leaves literal asterisks.
- #104 (medium): `reversed` lists numbered 1, 0, 0; an empty first item
  starts the list at 2, which renders as text. Family 1.
- #105 (low): a block inside `<pre>` loses the line break after it.
- #106 (low): pipe tables in document order, unlike `html_table()`. Family 3.
- #107 (low): adjacent lists of one kind merge.
- Oracle used: `commonmark::markdown_html()` (cmark-gfm), reparsed and
  compared; this is the oracle #69 asks for.

### 13. Trim preformatted text when `trim = TRUE` — #108, medium

- `src/zuh_text.c`: `<pre>  a  \n\n</pre>` keeps its whitespace; reaches
  `html_table()` and `html_list()`.

## Cross-cutting

- **Encodings are the package's largest weakness.** Nine findings (#81,
  #85, #89 to #95) and every one in code the assurance file already listed
  as hand-checked. The design delegates decoding to the platform `iconv()`,
  whose tables and state handling are neither the Encoding Standard's nor
  the same across platforms. One decoder implemented from the WHATWG
  indexes would close #81, #89 and #91 together, and make results
  platform-independent.
- **Guards on one route, not its sibling (family 3) is the commonest
  shape:** #91, #92, #96, #98, #99, #106, plus #82 and #84.
- **Candidate rule for `correctness.md`: a string has one meaning.**
  #88 (jsonlite reads a string as a path or URL), #92 (`enc2utf8()` gives a
  string a different byte meaning by locale), #96 (an ID becomes selector
  syntax) and #93 (a byte label used as text) all hand untrusted text to an
  API that reinterprets it. Proposed wording: *"Untrusted text crosses into
  another API only as data: never through a function that may treat it as
  a path, URL, pattern, selector or locale-encoded string. Pass it to the
  narrowest data-only entry point, or quote it for that grammar and test the
  quoting with every metacharacter."* To be raised in `pedrobtz/packages`.
- **Emitters were hand-checked only.** Running `commonmark` over the
  Markdown output found seven bugs in an afternoon; the round-trip oracle
  is cheap and absent.

## Held: what was probed and stood

- `html_limits()` value matrix on every argument; condition fields; every
  limit straddled at ±1 on character, raw, path, `file://`, connection,
  gzip and raw connections; decoded versus raw units for latin1, UTF-8 and
  UTF-16; limit interplay order.
- `max_depth` through reparenting (adoption agency, foster parenting),
  templates and foreign content; `max_memory` bisected and monotone; 2000
  failed parses leave no growth.
- Prescan: 45 cases against the algorithm, the 1024-byte window, label
  whitespace and case, replacement and x-user-defined labels; BOM
  precedence.
- UTF-16 decoder edges; UTF-8 strictness; truncated multibyte tails;
  IBM866, ISO-8859-2 to 16, KOI8-R, macintosh and mapped windows-125x bytes
  against reference tables.
- Selectors: about 230 cases including attribute operators and flags, case
  rules by namespace, escapes, `:nth-*` arithmetic to ±1e9, `:not` nesting,
  every rejected form with its position; selector caps at ±1.
- Text: about 55 `html_text_clean()` cases; `html_text()` equals the paste
  of `html_strings()`.
- Tables: section ordering, spans at 0, 999, 1000, 1001, 65535, overlap
  errors, `max_table_cells` at ±1, header modes, about 45 conversion cases.
- URLs: all 41 RFC 3986 §5.4 examples and 70 more pairs; `<base>` rules.
- Serialization: 60 documents reparsed and compared; only the adjudicated
  classes differ.
- Markdown: escaping of every line-start and inline construct listed in
  #101's held list; 1,500 random documents with no link-target differences.
- Nodeset operations, dead and tampered objects, navigation on mixed
  nodesets, `html_attr()` by namespace, forms and microdata rules, hostile
  session (`OutDec`, `scipen`, `digits`, `warn = 2`, `TZ`) byte-identical
  apart from #92 and #110.

## Not reproduced, and by design

Every reproduced trigger was re-run and reproduced. By design, with
citations:

- `pretty = TRUE` changes word boundaries: design §7, "not a round-trip
  format".
- Dot-segment removal on opaque URIs and `..//c` against `x:/a/b`: design
  picks strict RFC 3986 §5.2.2.
- `encoding = "UTF-16"` without a BOM is big-endian: design §5.
- Problem columns count code points with tab stops, `byte_offset` bytes:
  "as Gumbo counts them".
- Repeated header labels collapse: design §9.
- Legacy bytes the Encoding Standard leaves undefined are an error: design
  §5, "nothing is decoded leniently".

Surprises not filed: a fragment admits `max_depth - 1` levels (the hidden
`<html>`); `comments = FALSE` leaves adjacent text nodes; `html_info()$encoding`
echoes the argument as typed; `<base href="javascript:...">` is honoured;
`:nth-child(2147483647n+1)` is "number too large"; `as.character(doc)`
lists the object's fields.
